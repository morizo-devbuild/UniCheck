# UniCheck
UniCheck is a Telegram bot designed to help students find universities based on the student's preferred country and field of study.

### Features
* **UniSearch** - searches universities based on the student's preferred country and field of study. *AI integration in progress*
* **UniMatch** - matches universities with the student based on their preferences. *Planned*
* **AppTrack** - tracks application and deadlines. *Planned*

### Built with:
* n8n
* Telegram Bot API
* JavaScript

### Project status
UniCheck is currently in development.
The first function, **UniSearch**, is mostly functional. The main remaining challenge is implementing AI-powered recommendations.

### Challenges & Learning
While building UniCheck, I learned about:
- connecting APIs and automation workflows
- handling user input and validation
- working with databases
